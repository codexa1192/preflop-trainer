Security Policy
===============

Supported project
-----------------

This repository hosts a public static GitHub Pages site.

Reporting a vulnerability
-------------------------

Report suspected vulnerabilities privately to the repository owner or through GitHub private vulnerability reporting if available. Do not include secrets, credentials, PHI, PII, customer records, exports, logs, or other private data in public issues or pull requests.

Expected handling
-----------------

Security fixes should use pull requests, keep `main` protected, and pass any enabled repository checks before merge.
